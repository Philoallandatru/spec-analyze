# 规范族与适用范围（Specification Family and Scope）

NVMe 不是一本孤立的文档，而是一个由**基础规范、I/O 命令集规范、传输规范、NVMe-MI 管理接口规范和引导规范**组成的协作**规范族（Specification Family）**。各规范之间是平级协作的"适用范围"关系（而非协议栈分层），共同确保主机软件与 NVM 子系统的互操作性。[PDF p. 23](../_source/pages/page-023.md)

可以把 NVMe 规范族想成**一栋写字楼的手册体系**：
- **基础规范（Base）** = 楼宇总规（约定大堂、电梯、公共协议，所有设备都遵守）
- **I/O 命令集规范** = 各部门规章（NVM 块存储、KV 键值、ZNS 分区各自扩展专属命令）
- **传输规范** = 楼内布线指南（把协议绑定到 PCIe、RDMA、TCP 或光纤通道上）
- **NVMe-MI 规范** = 物业远程抄表接口（带外管理，不经过主机驱动也能监控设备）
- **引导规范（Boot）** = 大楼迎宾与启动指南（定义系统如何从 NVMe 设备启动）

---

## 规范族成员与协作关系

```text
                    I/O 命令集规范
                    (NVM / KV / ZNS 等)
                          |  扩展命令与数据结构
                          v
  NVMe-MI <--------> NVMe 基础规范 <--------> 引导规范
  (带外管理)        (传输无关核心协议)        (系统启动)
                          ^
                          |  绑定到具体介质
                    传输规范
              (PCIe / RDMA / TCP / FC)
```

> **设计意图**：上图箭头（基于 Figure 1）表示**适用范围**，不表示协议分层或系统架构。例如开发一块 PCIe NVMe SSD 驱动时，需同时参考基础规范、PCIe 传输规范和 NVM 命令集规范。[PDF p. 23](../_source/pages/page-023.md)

## 基础规范的管辖边界

基础规范通过"接口与实现分离"，允许物理 SSD、网关设备以及虚拟化软件控制器遵循同一套协议契约互操作：[PDF p. 24](../_source/pages/page-024.md)

| 边界分类 | 包含内容 |
|----------|----------|
| **规范范围之内** | 控制器的属性与行为（涵盖 I/O、Discovery 和 Administrative 三类控制器）；管理与 I/O 命令；各命令集共有特性；主机与控制器的交互协议 |
| **规范范围之外** | 具体使用模型（SSD / 主存 / 缓存 / 备份等）；存储介质管理算法（磨损均衡、擦除策略、FTL、缓存算法）；底层物理互联本身（如 PCIe/TCP/RDMA 原生规范） |

## 需求关键字与编码约定

阅读规范时，关键字决定了实现的一致性要求，保留字段的规则则保障了向后/向前兼容性：[PDF pp. 24-25](../_source/pages/page-024.md)

| 关键字 / 约定 | 含义与处理规则 |
|---------------|----------------|
| **`mandatory` / `shall`** | **强制要求**：为保证互操作性必须严格遵守 |
| **`should`** | **强烈建议**：除非有充分理由，否则应遵循 |
| **`optional` / `may`** | **可选 / 允许**：可不实现，但一旦实现 `optional` 功能就必须符合规范定义 |
| **`obsolete`** | **已废弃**：早期版本存在、现已移除（仅保留字面以兼容旧文档） |
| **保留字段（Reserved）** | 写入时**必须清零**（不可作为私有扩展）；读取时**必须忽略**；收到保留编码值应报错（向控制器写保留编码的结果未定义）。图表空间不足时缩写为 `R` |
| **数值与单位约定** | 数值默认 **1-based**（除非明确说明 0-based）；二进制单位用 `Ki/Mi/Gi`（$2^{10}$ 幂），十进制用 `k/M/G`（Figure 2）；ASCII 字符串仅限 `20h–7Eh`，左对齐右侧补空格 |

## 关联与引申概念

- **三类控制器**：基础规范区分 **I/O 控制器**（处理数据读写）、**Discovery 控制器**（NVMe-oF 发现服务）和 **Administrative 控制器**（纯管理），日常语境多指 I/O 控制器。
- **NVMe-MI（Management Interface）**：独立于主机带内驱动的带外管理协议，常通过 SMBus/I2C 或 PCIe VDM 运行，供服务器 BMC 管理存储设备。
