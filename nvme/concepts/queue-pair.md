# 队列对（Queue Pair）

NVMe 通过由**提交队列（Submission Queue, SQ）**和**完成队列（Completion Queue, CQ）**组成的队列对，在主机和控制器之间传递命令与完成状态。其中 **Queue ID = 0** 固定为管理队列（Admin Queue）处理控制命令，**Queue ID = 1–65535** 为 I/O 队列承载数据读写命令。[PDF pp. 28, 41-43](../_source/pages/page-041.md)

可以把队列对想成**餐厅的点单与出菜流水线**：
- **SQ（提交队列）** = 服务员放点菜单的托盘架（主机写命令，控制器消费）
- **CQ（完成队列）** = 厨房放"已上齐"回执的托盘架（控制器写完成条目，主机消费）
- **门铃寄存器（Doorbell）** = 内存模型下服务员按的"催菜铃"（通知对方队列指针已前进）
- **阶段标签（Phase Tag）** = 牌子上的"翻面贴纸"，CQ 每环绕一圈翻转一次，让主机无需读寄存器即可识别新完成条目

## 工作流程与两种传输模型

```text
  主机                  提交队列(SQ)         控制器          完成队列(CQ)
   |  写入 SQE 命令 ----->|                  |                 |
   |  通知(门铃/胶囊) --->|----------------->|                 |
   |                     |    解析并执行     |                 |
   |                     |                  |--- 写入 CQE ---->|
   |<---------- 中断(MSI-X) / 轮询(Phase Tag 翻转) -------------|
   |  通知 CQ 头部已消费 <--------------------------------------|
```

NVMe 支持**基于内存（如 PCIe）**和**基于消息（如 NVMe over Fabrics）**两种传输模型，它们在队列映射和流控上存在本质差异：[PDF pp. 29, 42-43, 59-60](../_source/pages/page-042.md)

| 对比维度 | 基于内存的模型（PCIe） | 基于消息的模型（Fabrics） |
|----------|------------------------|---------------------------|
| **队列映射** | Admin 严格 1:1；多个 I/O SQ 可共享一个 I/O CQ（多对一） | Admin 与所有 I/O 队列均**严格 1:1**，不支持多对一共享 |
| **命令提交** | 写入 SQ 内存槽位后，写 SQ 尾部门铃寄存器（MMIO） | 将命令封装为**命令胶囊（Capsule）**投递到传输层 |
| **完成检测** | CQE 中的 Phase Tag 翻转，或 MSI-X 中断 | 接收**响应胶囊**（Phase Tag 不适用） |
| **流量控制** | 靠 SQ 尾/头与 CQ 头/尾部指针及门铃驱动 | 无门铃；SQ 靠响应胶囊中的 `SQHD`（可协商禁用），CQ 无流控（主机须预留足够容量） |

### 命令处理特性
- **乱序执行与完成**：除**融合操作（Fused Operations）**外，控制器可按任意顺序执行同一 SQ 或跨 SQ 的命令，完成通知也可乱序返回。主机通过 CQE 中的 `SQID` + `CID`（Command Identifier）关联对应命令。[PDF pp. 59-60](../_source/pages/page-059.md)
- **队列优先级**：优先级（紧急、高、中、低）属于 SQ 属性（仅在加权轮询加紧急优先级仲裁模式下生效），而非单条命令的属性。

## 循环缓冲区与队列生命周期

### 循环缓冲区状态判断（单槽未使用规则）

队列大小 `QSIZE` 为 16 位 0-based 值，**最少 2 个槽位**（I/O 队列上限 65,536 受 `CAP.MQES` 约束；Admin 队列上限 4,096，消息模型还受 `ASQSZ` 限制）。为无需额外状态位即可区分"空"与"满"，NVMe 采用**单槽未使用规则**，实际可用深度为 `size - 1`：[PDF pp. 109-110](../_source/pages/page-109.md)

| 状态 | 指针关系 | 含义 |
|------|----------|------|
| **空（Empty）** | `Head == Tail` | 队列无待处理条目 |
| **满（Full）** | `(Tail + 1) mod size == Head` | 留一个空槽区分空/满；生产者必须等待 |
| **环绕翻转** | `Tail` 越过末端回到 `0` | CQ 每次环绕翻转一次 **Phase Tag**，指示新条目 |

### 基于内存的队列生命周期

```text
  配置 Admin 队列(AQA/ASQ/ACQ) ─> 协商队列数(FID 07h) ─> 创建 I/O CQ ─> 创建 I/O SQ
                                                                          |
  删除 I/O CQ <─────────── 删除所有关联的 I/O SQ <─────────────────────────'
```

1. **数量协商（FID `07h`）**：创建 I/O 队列前，主机通过 `Set Features`（Number of Queues）请求 SQ/CQ 数量（0-based）。分配结果在重置前固定；若已有 I/O 队列存在再修改此特性，会返回 `Command Sequence Error`。[PDF pp. 427-428](../_source/pages/page-427.md)
2. **中断合并（FID `08h` / `09h`）**：仅适用于 I/O 队列（Admin CQ 永不合并），可设置时间阈值（100µs 单位）或完成计数阈值（任一为 0 则立即中断），并通过 FID `09h` 按向量禁用合并。[PDF pp. 428-429](../_source/pages/page-428.md)
3. **创建与删除顺序**：**必须先建 CQ 再建 SQ**；删除时必须先删所有引用该 CQ 的 SQ，才能删 CQ。删除 SQ 会隐式中止所有未完成命令；队列级别重置本质上就是先静默排空，再删除并重建队列。[PDF pp. 107-108, 141, 441-445](../_source/pages/page-107.md)
4. **错误处理与未定义行为**：写入非法门铃值会触发异步事件并导致队列重建；在控制器消费前修改 SQE，或在主机消费前修改 CQE 均属于未定义行为。
5. **影子门铃（Shadow Doorbell）与 EventIdx**：针对虚拟化/仿真控制器的优化机制，主机与准虚拟化控制器通过两页内存镜像减少昂贵的 MMIO 门铃退出（VM-Exit），在控制器级别重置时失效。[PDF pp. 445-446, 702](../_source/pages/page-445.md)

### 基于消息的队列生命周期（Fabrics）

1. **Connect 建立**：在已建立的传输连接上发送一次 `Connect` 命令即可同时创建 SQ 与 CQ（重复 Queue ID 返回 `Command Sequence Error`），不使用 `AQA/ASQ/ACQ` 或 Create/Delete I/O Queue 命令。[PDF pp. 114-115](../_source/pages/page-114.md)
2. **流控协商**：默认启用 SQ 流控（响应胶囊携带 `SQHD`）；仅当主机置 `DISSQFC=1` 且控制器返回 `SQHD=FFFFh` 时禁用。向满 SQ 提交命令或违反流控属于致命错误，会置位 `CSTS.CFS` 并断开关联。[PDF pp. 117-118, 474-475](../_source/pages/page-117.md)
3. **Disconnect 删除**：`Disconnect` 是 SQ 上最后被处理的命令，其响应是该队列对消费的最后一个条目，形成提交屏障。仅当两端均支持隔离删除时，单条 I/O 队列断开才不会波及整个关联。[PDF pp. 115-117](../_source/pages/page-115.md)

## 实践排错提示

**场景：创建 I/O 队列报 `Invalid Queue Size`（状态码 `02h`）。**
- 检查传入的 `QSIZE` 是否小于 `2`（规范要求至少 2 个槽位，可用容量为 `size - 1`），或是否超过了 `CAP.MQES + 1`（`CAP.MQES` 为 0-based 最大值）。
- 同时确认 `CAP.CQR` 是否要求队列物理内存连续，以及创建队列总数是否超过了 `Get Features -f 0x07` 实际分配的数量。

## 关联与引申概念

- **Doorbell（门铃寄存器）**：PCIe 控制器 BAR0 中的 MMIO 寄存器，每个 SQ 尾和 CQ 头各占一个槽位（步长由 `CAP.DSTRD` 决定），主机写入新指针值通知控制器有新命令或已消费完成条目。
- **Phase Tag（阶段标签）**：CQE 中的 1 bit 标志位，初始化为 `0`，CQ 每次从末尾环绕回索引 0 时翻转，主机轮询内存即可零开销发现新完成的命令。
- **Capsule（胶囊）**：NVMe-oF 中在网络上传输的基本信息单元，封装了 64 字节 SQE（或 16 字节 CQE）及可选的内联数据或 SGL。
