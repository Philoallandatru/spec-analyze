# PCIe 时钟架构

**一句话总结**：PCIe 链路虽然在数据线上不单独传送时钟线（采用嵌入式时钟），但两端芯片仍依赖 **100 MHz 差分参考时钟（REFCLK）** 作为基准倍频；根据两端是否共用同一时钟源，分为 **Common Clock（共享时钟）** 和 **Separate Clock（独立时钟）** 架构，并通过 **SKP 有序集**与**弹性缓冲区**吸收微弱频差。

> **直观类比**：PCIe 通信就像两个鼓手异地合奏：
> - **Common Clock** 是两人听着同一个中央节拍器（主板 100 MHz 时钟发生器）打鼓，节奏完全同步；
> - **Separate Clock** 是两人各自看自己的手表（独立晶振），哪怕手表每天只差几微秒，时间久了也会错拍——因此每隔一段时间就得插入一个 **SKP（跳过节拍）** 口令来对齐节奏。

---

## 1. 100 MHz 参考时钟与嵌入式数据时钟

PCIe 的时钟体系分为两级：
1. **参考时钟（REFCLK+ / REFCLK-）**：主板通过专用差分引脚向插槽提供 **100 MHz ± 300 ppm**（百万分之 300）的 **HCSL**（高速电流舵逻辑）差分时钟。芯片内部通过 **PLL（锁相环）** 将 100 MHz 倍频到所需的高频工作时钟（如 4 GHz、8 GHz、16 GHz）。
2. **嵌入式时钟与 CDR（Clock and Data Recovery，时钟数据恢复）**：高速串行数据线上**没有**随路时钟线。接收端依靠 **CDR** 电路直接从收到的数据流电平跳变沿中提取采样时钟（这也是 8b/10b 编码和 128b/130b 加扰器必须保证足够跳变密度的原因）。

---

## 2. 两种主流时钟架构模式

| 架构模式 | 连接方式 | 优缺点与典型场景 |
|---------|---------|-----------------|
| **Common Clock（共享时钟）** | 发送端与接收端共用同一个 100 MHz 时钟发生器 | **优点**：频差为 0，抖动累积少、训练快。<br>**场景**：主板板载芯片、标准台式机插卡（最常见）。 |
| **Separate Clock（独立时钟，SRNS/SRIS）** | 链路两端各自使用独立的 100 MHz 晶振（允许 ±300 ppm 频差） | **优点**：无需在长距离线缆中拉参考时钟，支持独立电源域。<br>**缺点**：需更强的时钟补偿。<br>**场景**：跨机箱线缆互联（如 OCuLink/U.2 长线）、热插拔背板。 |

> **如何查看当前模式？**：配置空间 `Link Status` 寄存器中的 `Slot Clock Configuration` 位为 `1` 表示使用主板共享时钟（Common Clock），为 `0` 表示使用独立时钟。

---

## 3. 时钟补偿：弹性缓冲区与 SKP Ordered Set

在独立时钟模式下，即使两端晶振都在 ±300 ppm 容差内，发送端每秒发出的比特数仍可能比接收端本地时钟略快或略慢。若不处理，接收缓冲区迟早会溢出或读空。

PCIe 通过**弹性缓冲区（Elastic Buffer）** + **SKP（Skip）有序集**解决这一问题：
```
发送端时钟域 ──▶ [ 接收端 Elastic Buffer ] ──▶ 接收端本地时钟域
                        ▲
   缓冲区快满时：丢弃一个 SKP 符号（追赶进度）
   缓冲区快空时：复制插入一个 SKP 符号（补齐空缺）
```
发送端每隔固定间隔（Gen1/2 约每 1180–1538 个符号）就会在数据流中插入一组 `SKP Ordered Set`。由于 `SKP` 不携带任何业务数据，接收端物理层可以无损地增删它，从而实现跨时钟域的无缝平滑过渡。

## 4. 抖动预算（Jitter）与展频时钟（SSC）

### 抖动（Jitter）与 UI（Unit Interval）
**UI** 是传输 1 个比特的时间窗口（速率越快，UI 越窄）：
- **Gen1 (2.5 GT/s)**：1 UI = `400 ps`
- **Gen3 (8.0 GT/s)**：1 UI = `125 ps`
- **Gen5 (32.0 GT/s)**：1 UI = `31.25 ps`

总抖动（TJ）由**随机抖动（RJ，热噪声引起）**和**确定性抖动（DJ，串扰/失真引起）**组成。Gen5 要求总抖动必须控制在 `< 0.25 UI`（不到 8 皮秒！），因此高速 PCIe 对晶振相位噪声和电源去耦要求极其严苛。

### 展频时钟（SSC，Spread Spectrum Clocking）
100 MHz 及其倍频的强单频时钟会产生严重的电磁辐射（EMI）超标。PCIe 允许采用**下展频（Down-spreading）**技术：用 30–33 kHz 的三角波将时钟频率在 **0% 到 -0.5%** 之间微幅调制，把集中的辐射能量摊薄到更宽的频带上。
- **注意**：只有支持 **SRIS**（Separate Reference Clock with Independent SSC）的设备才允许两端各自开启不同的展频源，否则两端必须禁用 SSC 或使用同一展频时钟源（Common Clock with SSC）。

---

## 5. 低功耗下的时钟管理（L1.1 / L1.2 与 CLKREQ#）

在笔记本或现代节能服务器中，链路进入深度省电状态 **L1 子状态（L1.1 / L1.2）** 时，不仅数据收发器会休眠，设备还可以通过边带信号 **`CLKREQ#`** 通知主板完全关闭 100 MHz 参考时钟以进一步省电；当设备需要发送数据时，先拉低 `CLKREQ#` 请求主板恢复参考时钟，待 PLL 重新锁定后再恢复 `L0` 通信。
