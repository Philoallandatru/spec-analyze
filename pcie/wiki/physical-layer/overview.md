# 物理层概述 (Physical Layer Overview)

PCIe 物理层（Physical Layer）是协议栈的最底层，负责把上层的字节流变成芯片引脚上的高速差分电信号，并在对端无误地还原出来。如果把 PCIe 链路比作一条双向高速公路，**逻辑子块**负责给货物打包编号、分配车道，**电气子块**则负责把货车开上路面、在长途损耗后放大信号并保持车队步调一致。

---

## 物理层架构

物理层分为**逻辑子块（Logical Sub-block）**和**电气子块（Electrical Sub-block）**两大部分：

```text
+----------------------------------------------------------+
|             事务层 / 数据链路层 (TLP / DLLP)              |
+----------------------------------------------------------+
                             ↕
+----------------------------------------------------------+
|                   物理层 (Physical Layer)                 |
|  +----------------------------------------------------+  |
|  |         逻辑子块 (Logical Sub-block)                |  |
|  |  - 编码/解码：8b/10b (Gen1-2)、128b/130b (Gen3-5)  |  |
|  |  - 扰码/解扰 (Scrambling)：打散长连 0/1 降 EMI     |  |
|  |  - Lane 条带化 (Striping) 与去偏斜 (Deskew)         |  |
|  |  - 链路训练状态机 (LTSSM)：建链、协商、省电、恢复    |  |
|  +----------------------------------------------------+  |
|                             ↕                            |
|  +----------------------------------------------------+  |
|  |         电气子块 (Electrical Sub-block)             |  |
|  |  - SerDes：并串/串并转换                            |  |
|  |  - TX 驱动器与发送均衡 (Pre/De-emphasis, 3-tap FFE) |  |
|  |  - RX 均衡器 (CTLE, DFE) 与时钟数据恢复 (CDR)       |  |
|  |  - 差分信号收发 (TX+/TX-, RX+/RX-)                  |  |
|  +----------------------------------------------------+  |
+----------------------------------------------------------+
                             ↕
               物理介质 (PCB 走线 / 连接器 / 线缆)
```

---

## 逻辑子块核心机制

1. **编码与扰码**：
   - **Gen 1–2（8b/10b）**：每 8 bit 数据编码为 10 bit 符号（开销 20%），天然保证足够的电平跳变和直流（DC）平衡。
   - **Gen 3–5（128b/130b）**：每 128 bit 数据加 2 bit 同步头（开销仅 1.54%），必须配合 **LFSR 扰码器（Scrambler）** 打散连续的 `0` 或 `1`，以维持时钟恢复所需的跳变密度并降低电磁干扰（EMI）。
   - **Gen 6（PAM4 + 256B FLIT）**：采用 4 电平脉冲幅度调制（PAM4）和 1b/1b 固定 256 字节 FLIT 帧格式，并引入轻量级前向纠错（FEC）。
2. **多 Lane 条带化（Striping）与对齐（Deskew）**：
   - 发送端将 TLP/DLLP 字节轮流分配到各个 Lane（如 x4、x16）并行发送。
   - 由于 PCB 走线长度差异，各 Lane 到达时间会有微小偏差（Skew）。接收端利用周期性插入的 **SKP Ordered Set** 补偿时钟频偏并完成多 Lane 去偏斜对齐。
3. **链路训练与状态机（LTSSM）**：
   - 上电后自动完成对端检测（Detect）、位/符号锁定（Polling）、宽度与极性配置（Configuration），进入正常运行（L0），并在空闲时切换至省电状态（L0s/L1/L2）或在误码时进入恢复状态（Recovery）。

## 电气子块核心机制

### 1. 差分信号与全双工 Lane

每个 PCIe **Lane** 由两对单向差分线组成（共 4 根物理信号线），支持全双工通信：

```text
设备 A                              设备 B
+-------+                          +-------+
|  TX+  |-------- 正向差分 ------->|  RX+  |
|  TX-  |   (100Ω 差分特征阻抗)    |  RX-  |
|       |                          |       |
|  RX+  |<------- 反向差分 --------|  TX+  |
|  RX-  |                          |  TX-  |
+-------+                          +-------+
```

差分信号通过比较两根线的电压差（$V_{TX+} - V_{TX-}$）传输 `0` 和 `1`，对外部共模噪声具有很强的免疫力。

### 2. SerDes 与时钟数据恢复（CDR）

- **SerDes（串行器/解串器）**：发送端把内部宽位并行数据（如 32/64/128 bit）串行化为高速 1 bit 流；接收端将其还原为并行数据。
- **PLL（锁相环）**：将主板提供的 100 MHz 参考时钟倍频至串行传输频率（如 Gen 3 为 8 GHz）。
- **CDR（Clock Data Recovery）**：PCIe 不单独传输随路时钟线，而是由接收端 CDR 电路直接从高速数据流的电平跳变沿中提取采样时钟。若数据长时间没有跳变，CDR 就会失锁。

### 3. 发送端与接收端均衡（Equalization）

信号频率越高，PCB 走线的高频衰减越严重，前后符号会相互拖尾叠加形成**码间干扰（ISI）**，导致接收端眼图闭合。Gen 3+ 引入了完整的链路均衡机制：

- **TX 发送端**：使用 **3-tap FFE（前馈均衡器）**，包括前置抽头（Pre-cursor）、主抽头（Main cursor）和后置抽头（Post-cursor），通过**去加重（De-emphasis）**或**预加重（Pre-emphasis）**提前补偿高频损耗。
- **RX 接收端**：
  - **CTLE（连续时间线性均衡器）**：模拟高通滤波器，放大衰减的高频分量、压低低频分量。
  - **DFE（判决反馈均衡器）**：根据已判决的历史比特，直接从当前采样电压中减去历史拖尾干扰，且不会放大噪声。

## 各代 PCIe 物理层演进对比

| 代数 | 信号速率 | 调制 / 编码 | 单向单 Lane 有效带宽 | x16 单向带宽 | 典型无 Retimer 走线极限 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Gen 1** | 2.5 GT/s | NRZ / 8b/10b | 250 MB/s | 4 GB/s | ~50 cm |
| **Gen 2** | 5.0 GT/s | NRZ / 8b/10b | 500 MB/s | 8 GB/s | ~50 cm |
| **Gen 3** | 8.0 GT/s | NRZ / 128b/130b | ~985 MB/s | ~15.75 GB/s | ~20–30 cm |
| **Gen 4** | 16.0 GT/s | NRZ / 128b/130b | ~1.97 GB/s | ~31.5 GB/s | ~10–15 cm |
| **Gen 5** | 32.0 GT/s | NRZ / 128b/130b | ~3.94 GB/s | ~63.0 GB/s | ~7–10 cm |
| **Gen 6** | 64.0 GT/s | PAM4 / 256B FLIT | ~7.56 GB/s (有效载荷) | ~121 GB/s | 需超低损耗板材或 Retimer |

> **说明**：GT/s（Giga Transfers/s）是物理层每秒传输的符号次数，乘以编码效率后才是有效数据带宽。

## 电源状态与日常观测

物理层支持多级低功耗状态（由 ASPM 或软件电源管理触发）：

- **L0**：全速收发状态。
- **L0s**：单向快速待机（退出延迟 < 1 μs），仅关闭 TX 驱动，PLL 保持锁定。
- **L1 / L1.1 / L1.2**：双向深度睡眠（退出延迟数 μs 至 ~100 μs），L1.1/L1.2 会进一步关闭参考时钟（CLKREQ#）和共模电压。
- **L2 / L3**：主电源关闭（唤醒需重新走完整的链路训练）。

在 Linux 下可通过 `lspci` 快速确认物理层协商结果：

```bash
lspci -vvv -s 01:00.0 | grep -E "LnkCap|LnkSta"
# LnkCap: Port #0, Speed 16GT/s, Width x4   <- 硬件最大能力
# LnkSta: Speed 16GT/s (ok), Width x4 (ok) <- 当前实际协商状态
```

## 关联与引申概念

- **SerDes 与 CDR**：串并转换器与时钟数据恢复电路，是高速串行总线摆脱并行时钟线限制的基石。
- **差分信号**：通过 `TX+/TX-` 电压差抗共模干扰并降低电磁辐射，详见 [电气规范](electrical-spec.md)。
- **预加重 / 去加重 / CTLE / DFE**：发送端与接收端的信号补偿手段，详见 [链路均衡](link-equalization.md)。
- **扩频时钟（SSC）**：对 100 MHz 参考时钟做 -0.5% 向下展频调制以降低 EMI 峰值，详见 [电气规范](electrical-spec.md)。
- **LTSSM**：控制物理层建链、协商与恢复的状态机，详见 [LTSSM 状态机](ltssm.md) 与 [链路训练](link-training.md)。
- **Retimer vs Redriver**：用于延长 Gen 3+ 高速走线距离的信号中继芯片，详见 [Retimer 详解](retimer.md)。
- **编码与带宽**：8b/10b、128b/130b 与 PAM4/FLIT 的详细格式与带宽计算，详见 [编码方案](encoding.md) 与 [速度与编码](speed-encoding.md)。
- **Lane 反转与极性反转**：PCB 布线时允许反接 Lane 顺序或 `+/-` 极性，由物理层训练时自动纠正，详见 [链路宽度](link-width.md)。
