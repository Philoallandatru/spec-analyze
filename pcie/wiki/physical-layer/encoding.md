# 物理层编码方案 (Physical Layer Encoding)

物理层编码负责把上层传来的原始字节流转换成适合在高速铜线上传输的比特序列。如果把数据比作长途货运，**编码就像给货物装进带条形码的标准集装箱**：不仅要让接收端一眼认出每个箱子的边界，还要保证箱子上的黑白条纹（0 和 1）分布均匀，避免电路“看走眼”或产生直流漂移。

---

## 为什么需要物理层编码？

PCIe 物理层编码主要解决 4 个核心问题：

1. **时钟恢复（Clock Recovery）**：PCIe 没有独立的时钟线，接收端靠 **CDR（时钟数据恢复）** 从数据跳变沿提取时钟，因此不能出现太长的连续 `0` 或连续 `1`。
2. **直流平衡（DC Balance）**：链路中串联了交流（AC）耦合电容，如果 `1` 和 `0` 数量长期失衡，会导致信号基线漂移、判决出错。
3. **带内信令与定界（Framing）**：需要特殊控制符来标记 TLP/DLLP 的起始、结束、空闲和训练序列。
4. **提高有效带宽**：在保证上述特性的前提下，尽量降低编码本身的开销。

| 代数 | 编码方案 | 信号速率 | 编码效率 | 开销 |
| :--- | :--- | :--- | :--- | :--- |
| **Gen 1 / Gen 2** | 8b/10b | 2.5 / 5.0 GT/s | 80% | 20% |
| **Gen 3 / Gen 4 / Gen 5** | 128b/130b + 扰码 | 8.0 / 16.0 / 32.0 GT/s | 98.46% | 1.54% |
| **Gen 6** | 1b/1b + PAM4 + 256B FLIT | 64.0 GT/s (32 GBaud) | ~92.2% (TLP 载荷) | FLIT 头部 + CRC + FEC |

## 8b/10b 编码（Gen 1–2）

### 基本原理

8b/10b 将每 **8 bit** 原始字节拆分为 **5 bit + 3 bit**，分别查表映射为 **6 bit + 4 bit**，组合成 **10 bit 符号**：

```text
原始 8-bit 字节 (HGF EDCBA)
   ├── 低 5 位 (EDCBA) ──▶ 5b/6b 查表 ──▶ 6 位 (abcdei)
   └── 高 3 位 (HGF)   ──▶ 3b/4b 查表 ──▶ 4 位 (fghj)
                                              ↓
                                    10-bit 传输符号 (abcdeifghj)
```

8b/10b 天然保证**最多不超过 5 个连续相同位**，满足 CDR 要求，同时能检测出非法符号错误。

### 运行不等式（Running Disparity, RD）

为了维持直流平衡，每个 8b/10b 符号通常对应**正极性（RD+）**和**负极性（RD-）**两种 10 bit 编码。发送端跟踪当前累计的 `1` 和 `0` 数量差：
- 若当前处于 **RD-**（`0` 偏多），则优先选用 `1` 较多的 10 bit 编码，使之偏向 **RD+**；反之亦然。
- 接收端同步校验 RD 规则，一旦发现 RD 违例即可判定传输发生比特错误。

### 特殊控制字符（K-codes）

除了 256 个普通数据字符（D-codes）外，8b/10b 还定义了 12 个特殊控制字符（K-codes），用于包定界和链路管理：

| 符号 | 缩写 | 字节值 | PCIe 用途 |
| :--- | :--- | :--- | :--- |
| **K28.5** | COM | `0xBC` | Comma 逗号符，用于符号边界对齐与训练序列（TS1/TS2）起始 |
| **K27.7** | STP | `0xFB` | Start of TLP，标记事务层数据包开始 |
| **K28.2** | SDP | `0x5C` | Start of DLLP，标记数据链路层数据包开始 |
| **K29.7** | END | `0xFD` | End Good，标记数据包正常结束 |
| **K30.7** | EDB | `0xFE` | End Bad，标记作废/错误数据包结束 |
| **K28.0** | SKP | `0x1C` | Skip，用于时钟频偏补偿（Elastic Buffer 增删） |
| **K28.1** | FTS | `0x3C` | Fast Training Sequence，用于快速退出 L0s 省电状态 |
| **K28.3** | IDL | `0x7C` | Idle，链路空闲填充字符 |
| **K23.7** | PAD | `0xF7` | Pad，链路训练和通道对齐填充 |

**Gen 1/2 帧封装示例**：

```text
TLP:  [STP (K27.7)] [Seq# + Header + Payload + LCRC] [END (K29.7)]
DLLP: [SDP (K28.2)] [4B DLLP Content + 2B CRC]      [END (K29.7)]
```

## 128b/130b 编码（Gen 3–5）

### 为什么放弃 8b/10b？

8b/10b 的 20% 编码开销在高速下代价过高：若 Gen 3 要达到 8 Gb/s 有效带宽，用 8b/10b 需要 10 GT/s 的物理信号速率，功耗和信号完整性难度陡增。改用 **128b/130b** 后，开销降至 **1.54%**，8.0 GT/s 即可提供 7.877 Gb/s 有效带宽。

### 块结构与同步头（Sync Header）

128b/130b 每 16 字节（128 bit）前加 **2 bit 同步头**，构成 **130 bit 传输块**：

```text
+-------------+---------------------------------------------+
| Sync Header |              128-bit Payload                |
|   (2 bit)   |                 (16 字节)                    |
+-------------+---------------------------------------------+
```

- **`10b`（Data Block）**：16 字节全部为数据流（TLP/DLLP 字节按顺序紧密拼接，不再使用 K-codes，而是通过内嵌的 Token 如 STP/SDP/IDL 区分包边界）。
- **`01b`（Ordered Set Block）**：用于发送物理层控制序列（如 TS1、TS2、SKP、EIOS、EIEOS 等），首字节标识 Ordered Set 类型。
- **`00b` / `11b`**：非法同步头，接收端收到后触发物理层同步错误检测。

### 扰码器（Scrambler）

128b/130b 本身不限制连续 `0` 或 `1` 的长度，因此**必须配合扰码器**。发送端使用 23 位线性反馈移位寄存器（LFSR）生成伪随机序列与数据异或（XOR），接收端用完全相同的 LFSR 再次异或即可还原：

- 生成多项式：$G(x) = x^{23} + x^{21} + x^{16} + x^8 + x^5 + x^2 + 1$
- **注意**：Sync Header（2 bit）以及 SKP/TS1/TS2 等部分 Ordered Set 字段**不参与扰码**，以便接收端在未解扰前就能完成块同步与训练。

### 时钟频偏补偿（SKP Ordered Set）

由于发送端和接收端参考时钟存在微小频偏（如 ±300 ppm，或受扩频时钟 SSC 影响），接收端的弹性缓冲区（Elastic Buffer）会逐渐变满或变空。发送端会周期性插入 **SKP Ordered Set**（Gen 1/2 约每 1180–1538 符号，Gen 3+ 约每 370–375 个 128b/130b 块），接收端通过丢弃或复制 SKP 符号来吸收时钟差异，而不会影响真实数据。

## Gen 6 的编码演进（PAM4 + Gray 编码 + Precoding + 256B FLIT）

到了 64.0 GT/s 的 Gen 6，物理波特率保持 32 GBaud，但把传统的两电平（NRZ）改为四电平（**PAM4**，每个符号携带 2 bit）。由于眼高缩水为 NRZ 的 $1/3$（约 **-9.5 dB** 信噪比代价），Gen 6 物理层必须引入三项协同技术：

1. **Gray 编码（格雷映射）**：将 4 个电压电平映射为 `00 → 01 → 11 → 10`，相邻电平之间仅相差 1 个比特。这样即使噪声导致电压越界判到相邻电平，也只错 1 bit 而非 2 bit。
2. **1-Tap Precoding（预编码）**：发送端预先对符号做模 4 差分预编码，用来打破接收端 DFE 判决反馈的“连续错误传播（Error Propagation）”链条，把连串突发错误压缩回单个错误。
3. **256B FLIT + 轻量级 FEC**：取消 128b/130b 同步头，将数据统一封装为固定 **256 字节 FLIT**（236B TLP + 6B DLP + 8B CRC + 6B FEC）。借助 **6 字节轻量级前向纠错（FEC）**，把 PAM4 允许的原始误码率（First-Error $\sim 10^{-6}$）拉回至系统要求的 **$< 10^{-12}$**。

## 调试命令

```bash
# 查看当前链路速率（间接地确定正在使用的编码方案）
lspci -vvv -s 01:00.0 | grep -E "LnkCap|LnkSta"
# 2.5GT/s 或 5GT/s  -> 8b/10b
# 8GT/s, 16GT/s, 32GT/s -> 128b/130b
# 64GT/s -> PAM4 + 256B FLIT

# 检查 AER 中的物理层接收错误（Receiver Error 常与编码/同步错误相关）
lspci -vvv -s 01:00.0 | grep -A5 "CESta"
```

## 关联与引申概念

- **CDR（时钟数据恢复）**：依赖编码或扰码提供的跳变密度来锁定采样时钟，详见 [物理层概述](overview.md)。
- **扩频时钟（SSC）**：参考时钟的向下展频调制会引入动态频偏，需要靠 **SKP Ordered Set** 和 Elastic Buffer 吸收，详见 [电气规范](electrical-spec.md)。
- **PAM4 与 FLIT 模式**：PCIe 6.0 在 64 GT/s 下的调制与定长帧机制，详见 [速度与编码](speed-encoding.md)。
- **LTSSM 符号锁定**：Polling 阶段通过识别 `K28.5`（Gen 1–2）或 Sync Header/EIEOS（Gen 3+）建立字边界，详见 [LTSSM 状态机](ltssm.md)。
