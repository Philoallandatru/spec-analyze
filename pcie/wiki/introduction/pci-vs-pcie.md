# PCI vs PCIe：从共享并行到点对点串行

**一句话总结**：从 PCI 到 PCIe 的演进，是用“**点对点全双工串行包交换**”取代了“**多设备共享半双工并行总线**”，在物理层面彻底打破频率墙的同时，在软件层面完整保留了配置空间与驱动兼容模型。

> **直观类比**：
> - **传统 PCI** 像老式对讲机频道：32 根并排线一起喊话，所有设备挤在同一个频道里，每次只能有一个人说话（半双工），人一多就得排队抢麦克风（总线仲裁），且大家走得稍快就会因为脚步不齐（时钟偏斜）而听错话。
> - **现代 PCIe** 像专线光纤网络：每对设备之间拉一条独立双向专线（全双工），数据打包成快递包裹（TLP）独立收发，互不干扰。

## 五大核心技术差异

| 对比维度 | 传统 PCI / PCI-X | 现代 PCIe (PCI Express) | 演进收益 |
|---------|------------------|------------------------|---------|
| **传输方式** | 32/64 位并行单端信号 | 串行差分信号对（TX+/TX-, RX+/RX-） | 抗干扰极强，引脚数大幅减少 |
| **时钟机制** | 独立共享时钟线（33/66/133 MHz） | 嵌入式时钟（由接收端 CDR 恢复） | 消除并行线间的**时钟偏斜 (Clock Skew)** |
| **通信模式** | 共享总线、半双工、需总线仲裁 | 点对点专用链路、全双工、无仲裁 | 消除抢道延迟，读写可同时并发 |
| **协议层次** | 扁平总线时序（FRAME#/IRDY#/TRDY#） | 三层协议栈（事务层/链路层/物理层） | 支持 CRC 校验、硬件自动重传、流控 |
| **中断机制** | 4 根共享物理中断线（INTA#–INTD#） | **MSI / MSI-X**（基于内存写 TLP） | 最多 2048 个独立中断向量，可绑定指定 CPU 核 |

## 为什么并行总线跑不快，串行反而更快？

很多人初学时会疑惑：“一次传 32 位（PCI）难道不比一次传 1 位（PCIe）快吗？”

1. **时钟偏斜（Clock Skew）限制频率**：在并行总线上，32 根数据线必须与时钟线严格同时到达接收端。当频率超过百兆赫兹时，PCB 走线哪怕差几毫米，各比特到达时间就会错位，导致采样出错。
2. **串扰与电磁干扰（EMI）**：几十根单端信号线并排高速翻转，彼此之间的电磁串扰会急剧恶化，布线和阻抗匹配极其困难。
3. **差分串行 + 嵌入式时钟**：PCIe 每条通道（Lane）只用两对差分线（发一对、收一对），正负信号相减可抵消外部共模噪声；接收端直接从编码数据流的电平跳变中恢复时钟（CDR），完全不怕多条 Lane 之间存在微小长度差（物理层会自动做跨 Lane 对齐 Deskew）。

## 带宽与延迟对比

### 带宽演进

| 总线标准 | 规格 | 理论单向带宽 | 实际特征 |
|---------|------|-------------|---------|
| PCI 2.1 | 32-bit @ 33 MHz | 133 MB/s | 所有插槽设备共享这 133 MB/s |
| PCI 2.3 | 64-bit @ 66 MHz | 533 MB/s | 共享带宽，半双工 |
| PCI-X 1.0 | 64-bit @ 133 MHz | 1.06 GB/s | 早期服务器专用，布线极复杂 |
| **PCIe 3.0 x16** | 8.0 GT/s, 128b/130b | **~15.75 GB/s** | 独享、全双工（双向 ~31.5 GB/s） |
| **PCIe 4.0 x16** | 16.0 GT/s, 128b/130b | **~31.5 GB/s** | 独享、全双工（双向 ~63 GB/s） |
| **PCIe 5.0 x16** | 32.0 GT/s, 128b/130b | **~63.0 GB/s** | 独享、全双工（双向 ~126 GB/s） |
| **PCIe 6.0 x16** | 64.0 GT/s, PAM4 + Flit | **~121.0 GB/s** | 独享、全双工（双向 ~242 GB/s） |

### 中断与事务模式的飞跃

- **传统 INTx 共享中断**：PCI 只有 `INTA#`~`INTD#` 四根中断线，多个设备共享同一根 IRQ。中断发生时，操作系统必须依次轮询挂载在该线上的所有设备驱动（“这是你的中断吗？”），高并发下开销巨大。
- **PCIe MSI / MSI-X 消息中断**：PCIe 不再依赖物理中断线，而是让设备向 CPU 中断控制器指定的内存地址发送一条 **Memory Write TLP**。**MSI-X** 支持多达 **2048 个独立中断向量**，例如多队列 NVMe SSD 可以为每个 CPU 核心分配专属中断队列，彻底消除锁竞争与轮询开销。

## 软件兼容：硬件巨变，软件无感

尽管底层物理通信从并行总线变成了类似以太网的包交换网络，PCIe 在设计之初就确立了**软件向后兼容原则**：
1. **相同的配置空间骨架**：每个设备依然拥有 256 字节标准配置头（含 `Vendor ID`、`Device ID`、`Class Code` 和 6 个 `BAR`），PCIe 只是将配置空间从 256 字节扩展到了 4096 字节（通过 **ECAM** 内存映射机制访问）。
2. **相同的发现机制**：固件和操作系统依然通过 BDF 树形枚举发现设备；只是判断设备是否为 PCIe 时，会查找配置空间链表中是否存在 `PCIe Capability`（ID `0x10`）。

在 Linux 中可以用 `lspci` 快速分辨传统 PCI 与 PCIe 设备：

```bash
# 查看设备是否具备 "Express" 能力结构
$ lspci -vv -s 01:00.0 | grep "Capabilities:.*Express"
        Capabilities: [60] Express (v2) Endpoint, MSI 00
```
